## 처리 원칙과 현재 상태
서비스에 필요한 항목만 처리하고, 목적이 끝난 자료는 아래 절차로 삭제합니다. 이용자 자료를 판매하거나 광고 추적에 이용하지 않습니다. 이 문서는 현재 구현과 운영 구성을 설명하며 완전한 보안이나 법적 적합성 인증을 의미하지 않습니다.
현재는 개발 중인 서비스입니다. 해외 인프라의 처리 국가·보유 기간·계약상 수탁자 정보, 위치 기능의 법적 적용 사항은 운영 확인 중이며 일반 공개 운영 전 확정하여 이 방침에 보완할 예정입니다. 문의를 통해 현재 확인 가능한 범위와 선택 가능한 이용 방법을 안내받을 수 있습니다.

## 필수 항목·목적·기간
회원 가입 동의를 바탕으로 소셜 서비스 종류와 서비스별 식별번호, 직접 정한 닉네임, 내부 계정 식별자, 가입 시각, 동의 문서 버전·시각을 처리합니다. 목적은 계정 확인, 수집방 분리, 서비스 제공 및 동의 확인이며 회원 탈퇴까지 보관합니다. 프로필 설정을 완료하지 않은 계정도 자동으로 탈퇴되지 않으며 설정 화면에서 탈퇴할 수 있습니다.
서비스 이용 중 로그인 세션의 해시, 생성·만료·최근 사용·취소 시각을 처리합니다. 세션은 최대 7일, 미사용 24시간에 만료됩니다. 만료 기록은 서버 정리 작업에서 제거하며 로그아웃으로 취소된 기록은 최대 1일 후 제거합니다. 정리 작업은 서버 가동 중 약 1분 간격으로 수행합니다.
소셜 인증 요청의 상태·검증 정보, 과도한 요청을 제한하기 위한 IP 주소의 키 기반 해시와 선택한 방문자 자료 연결 정보는 최대 10분 유효하며 만료 후 정리합니다. 소셜 제공자의 접근 토큰은 연결 해제를 위해 최대 10분 동안 서버 메모리에만 보관하고 DB·파일에 저장하지 않습니다. 실명·이메일·소셜 프로필 사진을 회원 DB에 가져오지 않으며 로그인 권한 요청을 최소화했습니다. 제공자 설정으로 추가 정보가 응답되더라도 이를 회원 정보로 저장하지 않습니다.
동의를 거부할 수 있으나 필수 항목 처리를 거부하면 회원 기능을 이용할 수 없습니다. 만 14세 미만의 회원 가입은 지원하지 않으며 생년월일·신분증을 상시 수집하지 않습니다.

## 선택 항목과 이용 콘텐츠
직접 선택한 프로필 사진은 프로필 표시 목적으로 탈퇴 또는 교체·삭제까지 저장합니다. 사진을 제공하지 않아도 가입할 수 있습니다. 서버에서 256×256 JPEG로 다시 만들고 EXIF 등 원본 메타데이터를 제거합니다. 원본 프로필 파일을 별도로 보관하지 않습니다.
업로드한 사진·에셋·폴라로이드·다이어리 내용과 배치 정보, 상품 연결 및 개인 검색 기록은 요청한 기능의 제공을 위해 저장합니다. 직접 삭제하거나 탈퇴할 때 제거하며 에셋 휴지통에 남아 있는 자료도 탈퇴 삭제 범위에 포함됩니다. 사진에는 타인의 개인정보나 민감한 내용을 포함하지 않는 것을 권합니다.
SAM2·YOLO·깊이 처리·스티커 생성 및 임베딩 모델의 추론은 운영자의 로컬 PC에서 실행합니다. 외부 생성형 AI에 개인 사진을 보내 학습시키는 기능은 없습니다. 상품 검색 기능을 이용하면 검색어가 설정된 검색 서비스나 판매처로 전달될 수 있고 공개 상품 이미지·정보가 검색 캐시에 저장될 수 있습니다. 계정 식별자·프로필·다이어리 내용은 상품 검색 인자로 사용하지 않습니다.
선택형 주변 감지를 켜면 위도·경도·정확도·최근 수신 시각과 짧은 공유 세션을 서버 메모리에서만 처리합니다. 좌표를 DB나 파일에 기록하지 않습니다. 이번 거리·방향 공유에 별도로 동의한 서로 다른 사용자에게 약 300m 이내/300~600m/600m~1km의 거리 구간과 북쪽 기준 8방향별 인원수를 제공합니다. 같은 구간은 묶어서 표시하며 상대방의 좌표·닉네임·프로필 사진·사용자 식별자·정확한 거리나 방위각은 보내지 않습니다. 위치 오차가 크거나 가까워 방향이 불확실하면 거리만 표시합니다. 이 정보도 다른 정보와 결합하면 위치를 추정하는 데 쓰일 수 있으므로 원하지 않으면 공유를 켜지 않거나 즉시 끌 수 있습니다. 공유는 최대 15분이며 중지·로그아웃·탈퇴 시 종료합니다. 업데이트가 90초 끊기면 감지에서 제외하고 서버 가동 중 정리 간격을 포함하여 통상 105초 안에 메모리에서 제거합니다. 위치 권한 거부·중지로 일반 다이어리 이용을 제한하지 않습니다.

## 저장 위치·외부 서비스
회원 DB와 업로드 자료는 운영 PC에 저장합니다. 웹 화면 배포는 GitHub Pages, 외부 HTTPS 연결은 Cloudflare Tunnel, 로그인은 이용자가 선택한 Google·카카오·네이버를 이용합니다. 문의 이메일은 Gmail을 이용합니다. 따라서 모든 정보가 PC 안에서만 처리되는 것은 아닙니다.
GitHub와 Cloudflare는 서비스 제공·보안 운영 과정에서 IP 주소, 요청·기기 정보 등을 처리할 수 있으며 Cloudflare는 API 통신의 내용이 경유하는 구간입니다. 해외 인프라 처리 여부·수탁 관계·국외 이전의 대상 국가, 항목, 시기·방법, 보유 기간, 법적 근거 및 거부 방법은 실제 계약과 설정에 따라 확정해야 하는 사항입니다. 현재 확인 중인 정보를 임의로 확정하거나 이 안내에 대한 일반 동의를 국외 이전에 대한 별도 동의로 취급하지 않습니다.
외부 판매 링크를 열면 해당 판매처가 자체 정책에 따라 정보를 처리합니다. 그곳의 결제·주문 정보는 굿모닝이 수집하지 않습니다. 법령상 근거가 있거나 별도 안내·동의를 받은 경우 외에 이용자의 개인 자료를 제3자에게 제공하지 않습니다.

## 탈퇴·파기·백업
계정설정에서 탈퇴를 요청하면 모든 회원 세션과 위치 공유를 차단하고 회원 식별 정보·프로필·개인 콘텐츠·첨부 파일·개인 검색 기록을 삭제합니다. 실제 파일 삭제 실패 시 접근이 차단된 상태로 자동 재시도하며 문의 담당자가 상태를 확인할 수 있습니다. 진행 중인 작업이 있으면 완료 후 요청하도록 안내합니다.
프로젝트의 관리 백업 폴더에 있는 DB 백업은 생성 후 7일을 기준으로 삭제합니다. 서버가 꺼져 있으면 다음 가동 시 정리합니다. 백업에서 개별 행을 즉시 편집하지 않으므로 이 기간에는 삭제 전 자료가 백업에 남을 수 있습니다. 백업은 서비스 검색이나 일반 접근에 사용하지 않습니다.
백업 복원으로 탈퇴 계정이 다시 활성화되거나 예전 방문자 토큰이 재사용되는 것을 막기 위해 내부 계정 UUID, 소유자 식별자의 해시, 삭제 요청 시각을 최대 31일 보관합니다. 이는 개인정보일 수 있으며 이름·소셜 식별번호·사진·좌표는 이 기록에 포함하지 않습니다. 재접속 방지와 삭제 재시도에만 사용하고 만료 후 정리합니다. 삭제 재시도가 완료되지 않았다면 완료까지 필요한 기록을 유지합니다.
파일·DB 레코드 삭제는 애플리케이션의 논리 삭제 및 파일 제거 방식입니다. 저장 장치 전체의 물리적 덮어쓰기나 OS·사용자 별도 백업까지 자동 삭제한다고 보장하지 않습니다. 운영자가 별도로 만든 이전 자료·외부 백업은 공개 운영 전 목록과 파기 절차를 확인해야 합니다. 법적 보존 의무가 실제 발생하는 경우에는 그 근거·대상·기간을 따로 안내하고 분리 보관합니다. 현재 결제 서비스가 없어 전자상거래 기록을 이유로 모든 회원 자료를 일괄 장기 보존하지 않습니다.

## 브라우저 저장과 보호 조치
브라우저에는 연결 주소, 방문자 접근 토큰, 로그인 세션, 화면 설정 및 일부 다이어리 캐시가 저장될 수 있습니다. 방문자 토큰의 유효기간은 발급 후 30일이며 이전 형식은 2026년 12월 27일 UTC에 종료됩니다. 토큰 만료는 서버 자료의 자동 삭제를 뜻하지 않습니다. 방문자 자료의 삭제·접근 문제는 문의할 수 있습니다.
로그아웃은 회원 세션을 취소하고, 탈퇴 완료 화면에서 처음으로 이동하면 해당 브라우저의 굿모닝 저장 정보를 초기화합니다. 다른 굿모닝 탭이 열려 있으면 캐시 삭제가 지연될 수 있으므로 모두 닫아 주세요. 브라우저의 사이트 데이터 삭제 기능도 사용할 수 있으며 방문자 자료 접근 정보가 사라질 수 있습니다.
계정별 접근 검사와 DB 행 단위 권한, 검색 서비스의 DB 권한 분리, SQL 매개변수 처리, 입력·업로드 크기 제한, 프로필 사진 재인코딩, 로그인 세션 해시·만료, 외부 HTTPS 연결을 적용합니다. 키·회원 DB·개인 사진·백업은 공개 Git 저장소에 올리지 않도록 검사합니다. API의 일반 접근 로그를 끄며 비밀값이나 요청 원문을 운영 로그에 의도적으로 기록하지 않습니다. 저장 디스크 전체 암호화가 구현되어 있다고 주장하지 않습니다.
